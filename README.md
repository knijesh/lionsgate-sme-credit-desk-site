# Lionsgate Bank · SME Credit Desk (live demo)

**Open the demo:** https://knijesh.github.io/lionsgate-sme-credit-desk-site/

An agentic SME loan-origination demo: agents gather evidence, a deterministic policy engine
decides, people approve within their authority, and every step is recorded in a hash-chained
audit log. Everything runs in your browser; each visitor gets a private desk.

Lionsgate Bank is fictitious; every company, person and figure is generated.

This repository holds only the built site. The source is maintained privately.
